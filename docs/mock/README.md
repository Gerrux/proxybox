# Скриншоты и превью ссылок

Картинки в `docs/` — это настоящее окно из `ui/app-shell`, снятое
headless-Chrome с демо-данными вместо службы. Своей вёрстки у макета нет:
сменилось окно или версия — картинки переснимаются одной командой, без правки
макета.

```bash
pnpm install
node docs/mock/shoot.mjs
```

Только некоторые (имя без `-en`, снимаются оба языка):

```bash
node docs/mock/shoot.mjs interface flyout og
```

Нужны Chrome или Edge (другой путь — переменная `PG_CHROME`) и Python с Pillow
для пережатия палитрой; без Python картинки остаются, только втрое тяжелее.
Прогон целиком — около минуты.

## Что снимается

| Файл | Сцена | Где стоит |
| --- | --- | --- |
| `interface.png`, `interface-en.png` | «Защищено», белый список, карта | README (рус. и остальные) |
| `interface-failclosed.png`, `-en` | «Туннеля нет — доступ закрыт», весь компьютер | README, сайт |
| `first-run.png`, `-en` | первый запуск, карточка «С чего начать» | `quickstart.md`, `interface.md` |
| `settings.png`, `-en` | настройки | `interface.md`; `-en` — в не-русских README у абзаца про язык |
| `browsers.png`, `-en` | браузерные профили | `browser-profiles.md` |
| `flyout.png`, `-en` | плашка из трея, 380×520 | `interface.md` |
| `og.png` | превью ссылок 1280×640, английский текст | `og:image` сайта, social preview GitHub, обложки статей |

Русский набор — для `README.md`, `docs/*.md` и сайта, английский (`-en`) — для
`README.en.md`, `README.fa.md`, `README.zh.md`, `README.tr.md`, `README.id.md`
и статей. Окно 1000×700 в масштабе 1.5, плашка 380×520 так же. Social preview в
GitHub загружается руками: Settings → General → Social preview, файл `og.png`.

## Как устроено

- `shoot.mjs` поднимает Vite из `ui/app-shell` на свободном порту и вставляет в
  страницу `stage.js` до бандла, затем снимает сцены Chrome с
  `--virtual-time-budget`: опрос статуса, перелёт карты и полторы минуты
  графика скорости проходят за секунды. Тёмная тема — системная
  (`--force-dark-mode`), в настройках остаётся выбранной «Системная».
- `stage.js` подменяет `fetch("/ipc")`, которым окно в браузере ходит в службу,
  и отвечает демо-статусом. Сцена и язык — из адреса:
  `?scene=up|failclosed|first-run|settings|browsers&lang=ru|en`, плашка —
  `?flyout&scene=up`. Настройки и браузерные профили открываются так же, как их
  открывает человек: `Ctrl+,` и пункт рейки.
- `frame.html` — рамка для плашки: окно headless не бывает уже 500 px, а в
  окне шире плашка раскладывается иначе, поэтому она снимается в iframe
  точного размера, увеличенном `zoom`.
- `og.html` — превью ссылок: слева питч, справа то же окно в iframe.
- `squeeze.py` пережимает скриншоты окна в палитру из 256 цветов (`og.png` —
  нет: у неё градиент).

Данные вымышленные и одни на все сцены: домены `example.net`, адреса из
документационных диапазонов RFC 5737 (`203.0.113.x`, `198.51.100.x`), пути
приложений — стандартные каталоги установки.

Посмотреть сцены в браузере, не снимая: `node docs/mock/shoot.mjs --serve` —
поднимет тот же сервер и напечатает адреса. `pnpm --filter app-shell dev` для
этого не годится: там мост к живой службе.
